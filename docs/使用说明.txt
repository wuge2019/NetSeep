NetSeep 1.2.0 —— 轻量级网速悬浮窗 + 桌面宠物（参考火绒流量悬浮窗）
====================================================================

【怎么用】
  双击 NetSeep.exe，屏幕右上角出现小浮窗，桌面右下角出现小宠物，托盘出现图标。
  左键拖动 = 移动位置       右键 = 设置菜单
  双击    = 锁定/解锁位置   滚轮 = 调不透明度
  Ctrl+Alt+N = 开关鼠标穿透（只在开启穿透期间占用该热键）
  托盘图标双击 = 把浮窗拉回默认位置

【桌面宠物】
  一只跟着网速变状态的小家伙：
    无流量 → 睡觉（身体变灰、冒 z）      低速 → 发呆（瞳孔跟鼠标、随机眨眼）
    中速   → 踱步（迈小碎步）            高速 → 小跑（张嘴笑 + 拖速度线）
    极速   → 冲刺（星星眼、脸红、天线通红脉动）
  点一下 = 摸摸它（冒爱心、脸红，开心 2 秒；菜单里能看到累计被摸次数）
  拖动   = 给它搬家（位置自动记住）
  右键它 = 弹出和浮窗相同的菜单 → “桌面宠物”里可显示/隐藏、调大小 75%~200%、
           摸摸它、让它回到原位
  天线上的光球就是速度指示灯：暗灰（睡着）→ 主题色（正常）→ 琥珀（小跑）→ 通红（冲刺）
  全屏游戏或看视频时它会自动让位，退出全屏自动回来。

【菜单里能设置】
  桌面宠物（显示/隐藏、大小、摸摸它、回到原位）
  主题（深色 / 浅色 / 午夜蓝 / 石墨灰 / 高对比 / 极简透明 / 跟随系统 / 自定义）
  选择网卡 / 显示内容（上传、下载、迷你曲线图）/ 刷新间隔 / 不透明度
  置顶显示 / 锁定位置 / 鼠标穿透 / 全屏时自动隐藏 / 开机自动启动
  回到默认位置 / 关于 / 退出

【配置文件】
  %APPDATA%\NetSeep\config.ini（删掉即恢复默认）
  便携模式：在本目录建一个空文件 portable.txt，配置改存到 NetSeepData 子目录。
  与宠物相关的键：pet / petsize / petx / pety

【被 360 / 火绒 报毒怎么办】（重要）
  原因：小体积、没有数字签名、刚编译出来的 .NET 程序，会被杀软的云查杀/AI 引擎当成
        “从没见过的未知文件”送云端分析并提示风险。本程序不联网、不注入、不释放文件、
        不修改系统设置，只调用 GetIfTable2 读取系统网卡收发字节数用来显示速率。

  ① 立刻解决：加入信任区
     360：木马查杀 → 信任区 → 添加文件/目录 → 选中 NetSeep.exe（或整个目录）
          设置 → 白名单 里再加一条
          若弹出“发现未知文件/风险程序”，选“允许/信任”，别选“清除”（会直接删文件）
     火绒：防护中心 → 信任区 → 添加文件/目录
     Defender：Windows 安全中心 → 病毒和威胁防护 → 排除项 → 添加
     解压出来带“来自 Internet”标记的：右键 exe → 属性 → 勾选“解除锁定”
  ② 上报误报（按哈希加白，通常 1~2 个工作日）
     360：https://fuwu.360.cn/shensu
     火绒：火绒论坛“误报反馈”版块 / 客户端“上报样本”
     微软：https://www.microsoft.com/wdsi/filesubmission
  ③ 彻底根治：买一张代码签名证书，然后
     ..\build.ps1 -Pfx 你的证书.pfx -PfxPassword 密码
  ④ 一键自检与详细步骤：
     powershell -ExecutionPolicy Bypass -File ..\tools\check-false-positive.ps1

【命令行】
  NetSeep.exe --silent            启动但不弹首次提示（开机自启用）
  NetSeep.exe --dump 5            实测网速 5 秒（排错用）
  NetSeep.exe --list              列出所有网卡
  NetSeep.exe --preview 路径 [缩放] [主题]  生成界面预览图
  NetSeep.exe --themes 目录 [缩放]          每个内置主题各出一张预览图
  NetSeep.exe --pet 路径 [缩放]             宠物 6 种状态的对照图
  NetSeep.exe --reset             删除配置
  NetSeep.exe --help              帮助
  说明：本程序是窗口程序，只附着到调用它的控制台；双击运行时会写到
        %APPDATA%\NetSeep\last-output.txt 并弹窗提示路径。

【卸载】
  托盘菜单退出 → 删除本目录；如需清理：
  del "%APPDATA%\NetSeep" /s /q
  若开过“开机自动启动”，先在菜单里取消勾选。

【源码】
  ..\src\  （12 个文件，无混淆）；重新编译：..\build.ps1
